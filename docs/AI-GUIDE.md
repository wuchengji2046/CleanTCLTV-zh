# AI 辅助安装与适配

## AI 是可选助手

本项目是 Android 应用，电视运行不依赖 AI、AI 账号或 API Key。用户可以独立按 INSTALL.md 构建并安装；也可以让具备本地文件、命令行和 ADB 操作能力的 AI 助手协助首次安装及排查。

普通聊天工具只能解释命令；能否实际执行，取决于助手是否能访问电脑上的项目、SDK 和已授权的电视。不要把电视调试端口暴露到公网。

## 可复制给助手的任务

> 请先阅读本仓库 README.md、docs/INSTALL.md、docs/TCL-INSTALL.md 和 docs/RECOVERY.md。我的电视型号是【填写】，Android 版本是【填写】，局域网地址为【填写】。请先只读检查实际型号、原主页包名、固件及安装限制，判断是否适用于此仓库，再协助构建和安装普通应用版本。保留原厂主页、设置、TV、TV 卫士和硬件服务。先让我确认应用可正常显示、遥控器、设置及信号源可用，再设置无障碍跳转和自启动。不要刷机或照搬精简清单。不要覆盖其他无障碍服务设置。解释冷启动原主页闪现的限制，并记录可恢复步骤。不得公开我的 IP、ADB 密钥或签名密钥。天气城市由我在电视界面自行选择。

## 推荐顺序

1. 只读识别设备与固件，核对本项目实测范围。
2. 构建并安装，确认签名与已有版本兼容。
3. 手动打开，测试遥控器、应用入口、信号源和设置。
4. 用户启用主页跳转与 TV 卫士权限，测试 Home、重启和冷启动。
5. 用户选择天气城市。出现问题先关闭跳转，保留可回到原主页的路径。

不要把 AI 的判断当作固件兼容保证。其他型号仍需实机验证。日志可以帮助排查，但上传到公开 issue 前应移除个人信息。
