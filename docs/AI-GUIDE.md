# AI 辅助安装与适配

## AI 是可选助手

本项目是 Android 应用，电视运行不依赖 AI、AI 账号或 API Key。用户可以独立按 INSTALL.md 构建并安装；也可以让具备本地文件、命令行和 ADB 操作能力的 AI 助手协助首次安装及排查。

普通聊天工具只能解释命令；能否实际执行，取决于助手是否能访问电脑上的项目、SDK 和已授权的电视。不要把电视调试端口暴露到公网。

## 不限于 Codex

可以使用 Codex，也可以让 WorkBuddy 等其他具备本地执行能力的智能体协助。判断依据是能力和权限，而不是工具名称：需要能够读取和修改本项目文件、调用本机终端及 JDK/Android SDK、通过 ADB 连接已授权的电视，并读取命令结果进行排查。

[腾讯云 WorkBuddy 产品介绍](https://cloud.tencent.com/product/workbuddy)说明其支持本地文件操作；具体终端权限、网络访问和 ADB 环境仍须在用户电脑确认。本项目没有逐一实测其他智能体的完整安装流程，不保证所有版本或运行模式都可执行。仅能访问云端环境、无法连接电视所在局域网的助手，不能直接操作电视；只支持聊天的工具可以指导用户手动执行。

下面的任务模板不依赖特定品牌，交给满足上述条件的助手即可。安装完成后，电视无需智能体持续运行。

## 推荐顺序

1. 只读识别设备与固件，核对本项目实测范围。
2. 构建并安装，确认签名与已有版本兼容。
3. 手动打开，测试遥控器、应用入口、信号源和设置。
4. 用户启用主页跳转与 TV 卫士权限，测试 Home、重启和冷启动。
5. 用户选择天气城市。出现问题先关闭跳转，保留可回到原主页的路径。

不要把 AI 的判断当作固件兼容保证。其他型号仍需实机验证。日志可以帮助排查，但上传到公开 issue 前应移除个人信息。
